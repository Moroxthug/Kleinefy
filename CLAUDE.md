# Kleinefy — rules for anyone (human or Claude) working on this repository

These hold for this project and for every Kleinefy project.

Never use emojis. Anywhere: pages, copy, commits, replies.

Never add status labels or badges of the "Status: live", "Now live", "New", "Beta", "AI-powered" kind. If something is live,
the link proves it. Say what a product does, not what state a marketing page claims it is in.

No checklists or bullet lists in replies or on pages unless the user asks for one, or you ask first and they say yes.
Write in prose. A table is fine for data.

No eyebrow labels, grid backgrounds, gradient glows, "numbered pillars", italic-serif accent words, stock stat bands, or
other agency-template furniture. The reference for taste is poulo.site and its component library: system type, one grey
scale, one accent, motion only as a response to the reader (hover, scroll into view, pointer), everything pauses off
screen and respects reduced motion.

Type is the system face (-apple-system, SF Pro, then Segoe/Roboto), 16px/24px body, letter-spacing -0.02em, 600 for
headings. Palette: graphite ink #15171c, warm hairlines, brass #b5652d as the single accent, mirrored dark mode.

No invented numbers, testimonials, clients, team members or dates. If a fact is unknown, leave it out and say so in the
reply. Real product facts come from the live products.

Hand-written HTML, CSS and JavaScript. No frameworks, no UI kits, no effect libraries. When borrowing a pattern from
another library, re-implement it in our tokens and keep the author's licence notice.
